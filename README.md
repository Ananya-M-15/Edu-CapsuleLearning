# EduCaps 🎓
### Learn Something New Every Day

EduCaps is a micro-learning web application that transforms complex topics into bite-sized learning capsules. It helps users learn consistently through interactive lessons, quizzes, personalized progress tracking, and spaced repetition.

**[Live Demo](https://edu-capsulelearning-1.onrender.com/)** · **[GitHub Repository](https://github.com/Ananya-M-15/Edu-CapsuleLearning)**

## ✨ Features

- **Capsule-Based Learning** — Learn through short, structured lessons.
- **Personalized Dashboard** — Track learning progress and activity.
- **Interactive Quizzes** — Test knowledge with multiple-choice questions.
- **Contextual Tutor** — Get rule-based explanations and learning hints.
- **Learning Modes** — Standard and Kids modes with distinct mentor experiences.
- **Spaced Repetition** — Reinforce knowledge using the SM-2 algorithm.
- **Content Library & Search** — Explore subjects, topics, and capsules.
- **Admin Panel** — Manage learning content through Django Admin.
- **Responsive UI** — A modern interface with pastel visuals and interactive elements.
